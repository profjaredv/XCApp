Fix Coach Role - Simple Method

Step 1: Open Browser Console

Press F12 or right-click → Inspect → Console tab

Step 2: Copy and Paste This Code

// Simple fix for coach role fetch('/api/profile/fix-coach-role', { method: 'POST', headers: { 'Authorization': 'Bearer ' + localStorage.getItem('firebase:authUser:' + Object.keys(localStorage).find(k => k.startsWith('firebase:authUser:'))?.split(':')[2])?.match(/"accessToken":"([^"]+)"/)?.[1], 'Content-Type': 'application/json' } }) .then(r => r.json()) .then(data => { console.log('Result:', data); alert('Success: ' + data.message + '\nYour role: ' + data.user.role); location.reload(); }) .catch(err => { console.error('Error:', err); alert('Error: ' + err.message); });

Alternative: Manual Token Method

If the above doesn't work, get your token manually:

  1. In console, type: localStorage and press Enter
  2. Find the key that starts with "firebase:authUser:"
  3. Copy the "accessToken" value
